## Bhagva You

A responsive social-media product interface for sharing ideas, creative work, and community challenges.

Created by **Vinod Kumar** using HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Included experience

- Mobile-first adaptive home feed with desktop sidebar and discovery rail.
- Brand system with a custom Bhagva You wordmark, app-mark, light/dark themes, and accessible controls.
- Functional post composer, likes, saves, comments, follows, share-link feedback, story action, and theme switching.
- Featured daily **You Challenge**, live community activity, short-video navigation entry points, and creator suggestions.
